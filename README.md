# timryadovouu.github.io

Personal one-page site, built with Vite + React + TypeScript.
Live at **https://timryadovouu.github.io**

## Run locally

```bash
npm install      # once, to install dependencies
npm run dev      # dev server with hot reload (http://localhost:5173)
npm run build    # build static files into dist/
```

## Resume

The resume sources live in `resume/` as LaTeX (`resume-en.tex`, `resume-ru.tex`).
Compile them to PDF — either on [Overleaf](https://overleaf.com) or locally with
`pdflatex` — and drop the result into `public/` (`resume-en.pdf`, `resume-ru.pdf`),
where the site's download buttons point.
